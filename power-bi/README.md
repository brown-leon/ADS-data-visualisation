# Power BI Visualisation Projects

This folder contains data visualisation work created using Power BI.

The projects focus on dashboard layout, visual hierarchy, chart selection, and clarity of presentation. The emphasis is on design and visual communication rather than data preparation, modelling, or advanced analytics.

Individual project folders contain screenshots and brief documentation describing the visual design choices made.

## Dashboards

- **Executive Sales and Operations Dashboard**  
  Executive-level dashboard focused on tracking overall sales performance and identifying the primary operational drivers behind revenue trends, with an emphasis on clarity, hierarchy, and decision-focused visual design.

- **Operations and Cost Dashboard**  
  Visual overview of operational costs, fuel usage, and profit-related metrics.

- **Product Size and Distribution Dashboard**  
  Descriptive dashboard exploring product size characteristics and distribution patterns.
