# Product Size and Distribution Dashboard (Power BI)

This project presents a Power BI dashboard focused on analysing product size characteristics and distribution patterns using LEGO set data.

The dashboard emphasises descriptive analysis of product attributes, including average set size, distribution of set sizes, and variation across categories and time periods. The focus is on visual exploration and comparative context rather than sales performance or forecasting.

## Purpose

The dashboard is intended to support understanding of:
- How product sizes vary across decades
- Distribution of product sizes using standardised measures (Z-scores)
- Differences in average product size by category
- Overall patterns in product characteristics over time

## Visual Design Considerations

- Use of distribution plots to show spread and outliers  
- Line and bar charts to support temporal and categorical comparison  
- Clear labelling and layout to support interpretation  
- Consistent colour usage to maintain visual coherence  

## Notes

This project reflects student-level applied data visualisation work.

The dashboard uses controlled sample data for demonstration purposes only.  
Data preparation, modelling, and predictive analysis are not included in this repository.
