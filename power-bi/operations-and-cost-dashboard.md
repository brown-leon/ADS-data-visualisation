# Operations and Cost Dashboard (Power BI)

This project presents a set of Power BI dashboard screenshots focused on operational costs, fuel usage, and profit-related metrics.

The dashboard emphasises cost drivers, operational efficiency, and financial context rather than sales performance or demand analysis. Screenshots are used to demonstrate layout, visual hierarchy, and annotation choices.

## Purpose

The dashboard provides a high-level operational overview highlighting:
- Fuel expenses and cost trends
- Operational volume relative to fuel usage
- Cost structure comparisons (hybrid vs gas bikes)
- Estimated impact on profitability

## Visual Design Considerations

- Clear separation between outcomes (revenue, profit) and cost drivers  
- Use of annotations to guide interpretation  
- Minimalist layout to reduce cognitive load  
- Consistent colour usage to distinguish metric types  

## Notes

This project reflects student-level applied data visualisation work.

The dashboard uses controlled sample data for demonstration purposes only.  
Data preparation, modelling, and forecasting are not included in this repository.
