# QGIS Spatial Visualisation Projects

This folder contains spatial visualisation work created using QGIS as part of Applied Data Science coursework.

The projects focus on map-based visual communication, including the use of layers, symbols, and geographic context to present spatial patterns clearly. Emphasis is placed on visual clarity and appropriate map design rather than spatial modelling, prediction, or advanced geospatial analysis.

Individual project folders contain exported maps and brief documentation describing the visual and spatial design choices made.
